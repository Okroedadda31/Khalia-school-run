# Khalia School Run

A simple browser mini-game where the player jumps over obstacles and tries to score as high as possible.

## How to play

- Open `index.html` in a browser.
- Press the Start button or press Space/Up/W.
- Jump over cones/obstacles to avoid losing.
- Try to beat your best score.

## Controls

- Space
- Up Arrow
- W

## Notes

This is a polished single-file version using HTML, CSS, and JavaScript.
